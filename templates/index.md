# Authoring templates

공통 Template을 한국어 경로에 복사하고 표제의 한국어/영어 중 해당 언어를 선택한다. 영어 pair는 새 복사본을 독립 작성하지 않고 완성한 한국어와 의미를 맞춘다.

`REPLACE`를 실제 값으로 바꾸고 generated를 추가한다. 검증 전 verified/synced_at을 꾸며 넣지 않는다. 영어 translation은 [정책](../policies/translation.md)에 따라 추가한다. 각 문서의 위치는 [Architecture](../policies/architecture.md)를 따른다.
