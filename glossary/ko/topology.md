# Topology: 요소 사이 연결 구조

이 Frontend 학습 경로에서 topology는 서비스·장비 같은 요소와 그 사이 연결 구조를 뜻합니다. node는 요소이고 edge는 관계입니다. Web → API → DB에서 화살표를 호출 관계로 정의했다면 호출 방향을 나타냅니다. 화면 좌표인 layout과 다르며 연결만으로 장애 원인을 확정할 수 없습니다. React Flow는 이를 nodes와 edges로 표현합니다.[^source]
