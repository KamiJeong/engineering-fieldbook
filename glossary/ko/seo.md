# SEO: 검색 엔진 최적화

## 용어와 별칭

SEO는 Search Engine Optimization의 약어이며, 한국어로 검색 엔진 최적화라고 합니다.

## 정의

검색 엔진이 페이지를 이해하고 사용자가 검색을 통해 해당 페이지를 발견하도록 돕는 활동입니다. 사람이 방문할 이유를 판단하기 쉬운 제목과 정보를 제공하는 일도 포함합니다.[^seo]

## 예제로 이해하기

**가정:** 가상의 공방 페이지 제목을 “특별한 경험”에서 “초보자 도예 원데이 수업 — 하루공방”으로 바꿉니다. 어떤 수업인지 쉽게 판단하도록 한 예이며 실제 검색 순위 상승을 측정한 결과는 아닙니다.

## 혼동 방지

검색 광고를 구매하는 것과 같은 뜻이 아닙니다. 최적화를 했다고 색인이나 첫 순위가 보장되지는 않습니다. 생성형 AI 검색이 생겨도 SEO의 기본 원칙은 계속 관련이 있습니다.[^seo][^google-ai]
