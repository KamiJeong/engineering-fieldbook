# Topology: connections between entities

In this Frontend path, topology means entities such as services or devices and their connections. A node represents an entity and an edge a relationship. In Web → API → DB, arrows show call direction if defined as calls. Topology differs from coordinate layout and does not establish fault causation. React Flow represents it through nodes and edges.[^source]
