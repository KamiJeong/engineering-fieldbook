# Delivery

Scope and suggested learning order: GitHub and GitLab collaboration basics → CI/CD → Deployment strategy.

Current entries cover repositories, Issues, PRs/MRs, Wikis, and Pages on GitHub and GitLab. Start with reading and editing documents in a browser; detailed Actions and CI/CD configuration are later topics.
