# Architecture Decision Records

아직 ADR은 없다. 첫 기록은 `ko/ADR-0001-slug.md`와 `en/ADR-0001-slug.md`에 작성하고 각 언어 index를 만든다. 삭제된 순번을 재사용하지 않는다. 후속 결정은 새 번호를 사용한다.

기존 ADR의 Context/Decision은 보존한다. Supersede 시 기존 Status와 후속 링크만 보완하고 새 ADR에서 이전 기록을 연결한다.
