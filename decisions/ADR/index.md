# Architecture Decision Records

첫 결정은 ADR-0001에 기록했다. 다음 번호는 ADR-0002다. 삭제된 순번을 재사용하지 않는다. 후속 결정은 새 번호를 사용한다.

기존 ADR의 Context/Decision은 보존한다. Supersede 시 기존 Status와 후속 링크만 보완하고 새 ADR에서 이전 기록을 연결한다.
